# Meno 使用指南

[← 回到 README](../README.zh-CN.md) · [English](guide.md)

## 安装

需要 macOS 14 Sonoma 或更高版本。液态玻璃需要 macOS 26，并使用 Xcode 26 构建。

从[最新版本](https://github.com/whrss9527/meno/releases/latest)下载 `Meno.zip`，解压后把 Meno.app 移到“应用程序”文件夹。该版本为通用二进制（支持 Apple 芯片与 Intel）。从 0.10.0 起用 Developer ID 签名并经过苹果公证，双击就能打开。0.10.0 之前的版本使用临时签名，首次打开时请右键点按 Meno.app 并选择“打开”，或运行 `xattr -dr com.apple.quarantine /Applications/Meno.app`。

Meno 可以自己安装更新：检查到新版本后，在提示、“设置 › 关于”或 Meno 的菜单里选择“安装并重新打开”即可。“设置 › 关于”还会从新到旧列出你当前版本之后每个版本的改动。Meno 会从 GitHub 下载新版本，核对校验和、版本号与代码签名，替换自身后重新打开。如果 Meno 所在的文件夹不可写入，则会改为提供下载链接。

更新后，系统设置的“辅助功能”列表里可能还留着上一个版本的记录，它对新版本不生效。这时 Meno 会打开“设置 › 权限”，自动换成新版本的记录，macOS 随后会再次请求授权；也可以手动点“清除并重新授权”。从 0.10.0 起，发布包都用同一张 Developer ID 证书签名，之后的更新会保留授权；只有从临时签名的旧版本更新过来时会再请求一次。

## 功能

### 隐藏与显示

- **三个分区。** “常显”中的项目始终显示；“隐藏”中的项目按需出现；“暗格”存放几乎用不到的项目——它们从不出现在菜单栏中，只能通过托盘、快速打开或按住 ⌥ 点按来访问。
- **多种展开方式：** 点按 Meno 图标、点按或悬停在菜单栏空白处（悬停可设为需按住某个键）、在菜单栏上向下滚动或轻扫、使用全局快捷键，或把文件拖到菜单栏上，放到某个隐藏的项目上。
- **智能重新隐藏：** 延迟一段时间后、切换 App 或点按别处时、指针离开菜单栏时自动收起；项目的菜单打开期间不会收起。
- **按需腾出空间：** 展开时可暂时隐藏前台 App 的菜单，让一长排图标也能放得下。为此 Meno 会成为当前 App，直到项目重新隐藏；悬停、滚动或自动显示项目时，只有指针在菜单栏上且你没在打字时才会这样做，所以你打的字仍会进入原来的 App。
- **项目留在你放的位置：** App 重新启动后，macOS 有时会把它的图标放到菜单栏最左边、别的分区里，Meno 会把它移回来；一次有很多项目变了位置时，会先询问你。

### 玻璃界面

- **托盘（Shelf）：** 菜单栏下方的液态玻璃浮条，展示隐藏的项目。刘海附近菜单栏空间不够时尤其好用。选择“自动”展开方式时，只有放不下时才会使用托盘。被 macOS 挤到刘海后面的常显项目会排在最前面，依然可以点按。用快捷键打开时还可以用键盘操作：← 和 → 或 Tab 选择项目，也可以直接键入名称开头（支持拼音首字母），↩ 打开。还可以在访达中显示项目所属的 App 或直接退出它，适合没有程序坞图标的菜单栏 App。
- **快速打开：** Spotlight 风格的面板，支持模糊搜索、拼音与首字母匹配（如输入 “wx” 找到“微信”），用键盘打开任意菜单栏项目，也可以执行 Meno 的操作，比如应用场景或开启禅模式。↩ 打开，⌘↩ 打开辅助菜单，⌥↩ 在菜单栏中展开该项目，⌘1–⌘9 快速选择。按 ⌘K 或右键点按项目可以看到更多操作：移到其他分区、暂时显示、拷贝链接，或在访达中显示它的 App 并退出。
- **布局编辑器：** 在“常显”“隐藏”“暗格”三条通道之间拖移项目，或拖到通道里的任意位置调整先后顺序，其他项目会让出它要落下的位置；Meno 会替你完成 ⌘ 拖移。还可以给项目重命名、指定一个符号作为图标，macOS 没给出好名字或图标的项目也能一眼认出。项目很多时，按 ⌘F 可以查找；“暂时显示”能让隐藏的项目在菜单栏里停留 15 分钟到 4 小时，之后自动放回。
- **变化时显示：** 选定一些隐藏的项目，它们的图标或文字变化时（比如同步失败），Meno 会把它们显示一会儿。在你查看之前，Meno 图标、项目所在分组的图标和托盘上的小圆点会标出发生变化的项目。
- **分组：** 把相关的项目收进一个单独的图标。点按图标或按下分组自己的快捷键，组内的项目会在它下方的托盘里出现，平时不占菜单栏的位置。
- macOS 26 及以上使用液态玻璃；macOS 14 和 15 使用带高光边缘的磨砂玻璃效果。

### 个性化

- **规则：** “当麦克风正在使用时，开启禅模式。”条件包括前台或正在运行的 App、麦克风或摄像头正在使用、电池、电源与低电量模式、外接显示器或指定的显示器、菜单栏当前在哪块显示器上、时间段与星期几、所连接的网络（通过路由器识别，无需定位服务）、离线状态，以及你自己写的 shell 命令执行成功，规则可以要求全部条件满足或任一条件满足；动作包括展开或隐藏分区、应用场景、开启禅模式、移动指定项目，并可在条件结束后自动撤销。移动项目会等到你暂时不用鼠标和键盘时再进行。Meno 菜单里的“暂停规则”或它自己的快捷键可以暂时停用全部规则。
- **场景：** 存储“工作”“居家”“演示”等布局，可从菜单、规则或场景自己的快捷键一键切换。场景和规则可以导出成 `.meno` 文件，带到另一台 Mac 上或分享给别人；打开这个文件或把它拖到设置窗口上，会先列出里面的内容，再由你决定导入哪些。
- **禅模式：** 一个快捷键清空所有 App 图标，只保留系统状态，适合截图、录屏和演讲。
- **项目快捷键：** 在任何地方打开指定项目（Wi-Fi、蓝牙、计时器……），即使它处于隐藏状态。
- **链接：** 快捷指令、启动器和脚本可以通过 `meno://` 链接显示或隐藏项目、切换禅模式、应用场景或打开项目。场景和项目的菜单里都有“拷贝链接”。
- **标记：** 在菜单栏中添加空白、细线、圆点、SF 符号或简短文字标签，为图标分组。
- **洞察：** 完全本地的使用统计——展开次数、最常用的项目，以及“这个项目本周在隐藏状态下被打开了 12 次，要保持显示吗？”或把几个月没用过的项目移到暗格之类的建议。暂不采纳的建议两个月内不会再出现。
- **新图标提醒：** App 新增菜单栏图标时，可以询问你、自动隐藏或放入暗格。
- **外观：** 自选 Meno 图标（也可以用任意 SF 符号）、分隔符样式、托盘玻璃与着色；菜单栏着色可用自选颜色或取自墙纸的颜色，支持渐变、边框、阴影和分离式“岛屿”形状（实验性）；可调整系统级图标间距（测试版）。
- 支持英文、简体中文与繁体中文。默认跟随系统语言，也可以在“设置 › 通用 › 语言”中另选。

## 链接

| 链接 | 作用 |
| --- | --- |
| `meno://show`、`meno://show/all` | 显示隐藏的项目，或连同暗格全部显示 |
| `meno://hide`、`meno://toggle` | 重新隐藏，或在显示与隐藏之间切换 |
| `meno://zen`、`meno://zen/on`、`meno://zen/off` | 切换、开启或关闭禅模式 |
| `meno://scene/工作` | 应用名为“工作”的场景 |
| `meno://group/工具` | 在图标下方显示名为“工具”的分组 |
| `meno://open/Wi-Fi`、`meno://open/Wi-Fi?menu=secondary` | 按名称打开菜单栏项目 |
| `meno://quick-open`、`meno://shelf`、`meno://settings/rules` | 打开快速打开、托盘或某个设置页面 |

例如在终端里运行 `open meno://zen/on`，或在快捷指令里使用“打开 URL”操作。名字里有空格或中文时，用“拷贝链接”得到的是已经编码好的链接。

在 macOS 26 及以上，专注模式也能改变菜单栏：在快捷指令里为专注模式打开时添加一个自动化，用“打开 URL”操作打开某个场景的链接，例如 `meno://scene/Work`；再为专注模式关闭时添加一个。

## 工作原理

Meno 会在菜单栏中添加小小的分隔符：单箭头是“隐藏”分区的起点，双箭头是“暗格”的起点。分隔符左侧的一切都属于对应的分区。按住 ⌘ 把图标拖过分隔符，或使用布局编辑器即可调整。

隐藏某个分区时，它的分隔符会变宽，直到左侧的项目放不下：

- **宽分隔符引擎（macOS 14–26）：** 单个分隔符延伸到屏幕边缘之外。
- **阶梯式引擎（macOS 27）：** macOS 27 的菜单栏会丢弃宽度超过约半个屏幕的项目，而且一次性大幅改变长度不会带动相邻项目。Meno 会让分隔符和几个辅助占位项以 40 pt 为一步逐渐加宽，每个都略低于该上限。被推开的项目会进入系统的溢出菜单。可在“设置 › 通用 › 高级”中选择引擎。

使用宽分隔符引擎时，Meno 会在隐藏后检查隐藏的项目是否真的移出了屏幕。如果连续两次都没有移出，而引擎是 Meno 自动选的，它会在这个 macOS 版本上换用阶梯式引擎，并提示一次。诊断报告会显示隐藏是否已验证。

菜单栏项目通过各个 App 的辅助功能树读取，适用于所有支持的 macOS 版本，包括 macOS 27 的单窗口菜单栏。

## 占用

放着不动时，Meno 大约占用单个 CPU 核心的千分之一，内存 10 到 15 MB（按“活动监视器”的算法）。每次改动合并进主分支后，CI 都会测一遍：`scripts/measure-footprint.sh` 启动 App，放着不动一分钟，把数字写进这次运行的摘要。

| 放着不动一分钟，Apple 芯片 | macOS 26 | macOS 15 |
| --- | --- | --- |
| CPU | 单核的 0.13% | 单核的 0.12% |
| 内存 | 14.2 MB | 9.7 MB |
| 唤醒 | 每秒 0.1 次 | 每秒 0.1 次 |
| 查看一遍菜单栏（通常） | 37–49 毫秒 | 34–53 毫秒 |

- 大多数变化会即时通知 Meno，比如 App 启动或退出；Meno 只是每 20 秒（低电量模式下每分钟）把整个菜单栏查看一遍，补上漏掉的变化。显示器休眠或其他用户的会话在前台时不查看。
- 不在后台截取屏幕。
- 会运行命令或依赖网络的规则，只在这类规则开着时才做这些事。

测量在 GitHub 的 macOS 虚拟机上进行，机器上只有 macOS 自带的菜单栏项目；项目更多时，每次查看会稍久一点。

## 权限与隐私

| 权限 | 用途 |
| --- | --- |
| **辅助功能**（必需） | 读取菜单栏项目，通过托盘、快速打开和快捷键打开它们，并用 ⌘ 拖移进行整理。 |
| **屏幕录制**（可选） | 显示隐藏项目的真实图标（macOS 14–26）；开启后还能发现图标的变化。未授权时显示 App 图标。只会截取菜单栏项目，而且只在托盘、快速打开或设置窗口打开时，或比较图标期间截取；此时 macOS 会在菜单栏显示录屏指示器。 |

与麦克风、摄像头有关的规则只会询问 macOS 设备是否在运行，不需要任何权限，Meno 也不会录制任何内容。

带命令的规则条件只会运行你输入的那条命令：每 10 秒用 zsh 运行一次，且只在规则开启时运行。有规则用到网络条件时，Meno 会在网络变化时和每 30 秒运行一次 `route` 与 `arp`，它们只读取 macOS 已知的各个连接的路由器信息，不会发送任何数据。导入设置时，带命令的规则会被关闭，因此设置文件在你检查之前无法运行任何东西。导入替换你的设置之前，Meno 会先列出文件里有多少场景、规则和快捷键，并把当前设置备份为 `~/Library/Application Support/Meno` 里的 `settings.before-import-<日期>-<时间>.json`；点提示里的“撤销”即可恢复。

Meno 没有数据分析或账户。它只会在检查更新时联网，向 GitHub 查询最新版本和你当前版本之后各版本的说明：在“设置 › 关于”里点“检查更新”时，或在“通用”里开启每日检查后每天一次；此外只在下载你选择安装的新版本时联网。设置与统计数据保存在 `~/Library/Application Support/Meno`。

## 常见问题

- **更新后 Meno 没有反应。** 没有使用固定证书签名的版本，每次更新都会在“辅助功能”里产生一条新记录。Meno 会换掉旧记录，macOS 随后会再次请求授权；如果没有弹出请求，打开“设置 › 权限”，点“清除并重新授权”。
- **无法在 Meno 里安装更新。** Meno 只能在有写入权限的位置替换自身，例如管理员账户下的“应用程序”文件夹；macOS 从下载文件的临时副本运行 Meno 时也无法替换。这些情况下 Meno 会改为提供下载链接。
- **macOS 26 及以上找不到某个 App 的图标或 Meno 图标。** macOS 只显示在“系统设置 › 菜单栏”中被允许的 App 的项目。Meno 图标本身也可以在“设置 › 外观”中隐藏；可以通过快速打开、运行 `open meno://settings`，或再次打开 Meno 来进入设置。
- **挪动分隔符并点了它之后，图标不见了。** 单箭头分隔符左侧的一切都属于“隐藏”分区，所以把分隔符往右挪，它经过的图标就进了隐藏分区；点一下分隔符，它们会和分隔符一起被隐藏。点 Meno 图标，或点菜单栏上分隔符原来所在的空白处，即可重新显示，然后按住 ⌘ 把分隔符拖回去，或在“布局”面板里调整。被拖到 Meno 图标右侧的分隔符会在几秒内被移回图标左侧，这样隐藏时不会把 Meno 图标也藏起来；如果这期间图标不见了，可以运行 `open meno://show/all`。
- **移动过的项目又被移回去了。** 只有当某个 App 或 Meno 本身刚启动、而项目不在 Meno 运行时它最后所在的位置时，Meno 才会把项目放回；在 Meno 运行期间你自己移动的项目会留在你放的位置。如果不需要，可以在“通用 › 分区”中关闭“让项目留在你放的位置”。
- **macOS 每个月都会询问是否继续允许 Meno 录制屏幕（macOS 15 至 26）。** 屏幕录制是可选权限：不授权时，托盘显示 App 图标而不是项目本身的图案，项目变化也只通过文字来判断。
- **菜单栏出现紫色指示器，提示“Meno 正在捕捉你的屏幕”。** 每当 Meno 截取菜单栏项目的图标时，macOS 都会显示它：打开托盘、快速打开或设置窗口时（最多每 30 秒一次），以及打开“同时比较图标”后的每隔几秒。在屏幕录制权限中关掉 Meno 即可停止，Meno 会改为显示 App 图标。
- **macOS 把 Meno 叫作“Meno 2”。** 这台 Mac 上有两份 Meno，例如下载时保留了旧的那份。“设置 › 关于”会显示另一份的位置，保留一份即可。同一时间只会运行一份：打开另一份时会显示正在运行那份的设置；如果它更新，则由它接替。
- **Stats、iStat Menus 这类有好几个图标的 App，快捷键或场景里的位置失效了。** macOS 没给这类图标标识符时，Meno 靠图标的文字区分它们，而文字会随显示的内容变化，比如从“Battery: Charging”变成“Battery: 2:14 remaining”。这时 Meno 就找不到当初设置快捷键、场景或规则的那个图标了。这类图标的文字变化不会被当成新图标：Meno 改为数这个 App 显示了几个图标。诊断报告会给这些图标标上 *key may change*。
- 其他问题：在“设置 › 关于”中点“复制诊断报告”，即可复制 Meno 看到的信息，粘贴到 issue 里。

## 注意事项

- 移动项目是通过模拟 ⌘ 拖移完成的。在 macOS 14–26 上，Meno 把拖移直接发给每个项目自己的窗口，项目在原地移动，不占用指针；刘海后面的项目、全屏 App 收起菜单栏时也一样能移动。在 macOS 27 上，或者这样做不成功时，Meno 会展开所有项目并短暂接管指针，这需要菜单栏显示在屏幕上。时钟和控制中心图标无法移动。
- 图标间距使用 `NSStatusItemSpacing` 与 `NSStatusItemSelectionPadding` 偏好设置，App 只在启动时读取，因此应用时会重新打开带有菜单栏项目的 App。
- 菜单栏着色绘制在菜单栏后方，在 macOS 26 及以上的透明菜单栏上效果最明显。
- 有多块显示器时，每块显示器的菜单栏显示同样的项目、同样的顺序：macOS 把它们放在你正在使用的那块显示器的菜单栏上，其他显示器上也照样显示。Meno 在所有显示器上一起隐藏和显示它们。想按正在用的显示器来排列，可以在“设置 › 场景”的“各显示器的场景”里给每块显示器选一个场景：哪块显示器的菜单栏上有这些项目，就应用它的场景。想在大显示器上多显示一些，可以添加规则“在外接显示器上显示隐藏项目”，或使用条件“菜单栏在指定的显示器上”。
