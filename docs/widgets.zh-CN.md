# 菜单栏小组件

macOS 14 起，在桌面或通知中心的“编辑小组件”中选择 **Meno → 菜单栏快捷操作**。中尺寸组件提供显示图标、隐藏图标、开启禅模式和关闭禅模式四个入口。

编辑组件，输入最多两个已在 Meno 保存的场景的完整名称。场景入口通过与快捷指令相同的 `meno://scene/...` 命令应用场景。场景重命名或删除后，需要同步修改组件中的名称；空位置打开“设置 → 场景”，名称不存在时由主程序显示原有错误提示。

首版是操作面板，不显示推测的当前场景或禅模式状态。组件不读取主程序偏好、不请求辅助功能权限，也不自行移动菜单栏图标。点击后打开 Meno，由主程序按现有权限与错误处理完成操作；缺少辅助功能权限时在 Meno 的权限页授权。

主程序和 MenoCore 保留 SwiftPM。`scripts/build-widgets.sh` 使用固定版本 XcodeGen 2.44.1 生成独立扩展工程，在需要时构建双架构扩展，嵌入并先签扩展，再由 `build-app.sh` 签主程序。首版只有链接入口，不用 App Group 或新的 Apple 后台能力。

CI 校验嵌入、版本一致性、签名与 pluginkit 注册。发版前需要在 Mac 上安装正式 Developer ID 签名包，添加组件，在主程序运行和退出时分别测试四个内置操作与两个场景入口，再测试无权限和场景删除的情况。组件图库显示与真实点击仍是 macOS 验收项，不能用 Linux 测试成功代替。
