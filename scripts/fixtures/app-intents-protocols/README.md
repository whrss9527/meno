# Verified compiler contracts

These JSON arrays were generated by native Xcode builds in Meno#80 / PR#81, not inferred from SDK declarations. Xcode16.4 and26.3 ordinary SwiftPM extraction emitted no metadata; explicit emission using the corresponding13/17-name contracts produced the expected intent and shortcut on both SDKs (final probe38801054403).

The production build selects its matching contract, emits actual app constants, validates metadata for every Mach-O architecture and packages only validated output. A new Xcode major requires a new native control/probe before adoption. See docs/development.md.
